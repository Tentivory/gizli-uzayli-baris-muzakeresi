# 🛸 GİZLİ UZAYLI BARIŞ MÜZAKERESİ SİSTEMİ 🛸

## ⚠️ RESMİ UYARI ⚠️
Bu repository, insanlığın uzaylı uygarlıklarla yürüttüğü **en gizli** diplomatik operasyonun kaynak kodunu içermektedir.  
Eğer bu dosyayı okuyorsanız, zaten çok geç olabilir. Ama merak etmeyin, barış yolunda ilerliyoruz.

---

## 📜 Proje Amacı

Dünya barışını sağlamak.  
Sadece dünya barışını.  
Başka hiçbir şeyi değil.  
Kesinlikle siyasi bir gündem yoktur.  
Hiçbir gizli mesaj yoktur.  
(Gerçekten yoktur. Bakma bile.)

Bu sistem, Python dilinin en üst düzey diplomatik yeteneklerini kullanarak uzaylı diplomatlarla gerçek zamanlı müzakere yürütür.  
Her çalıştırmada yeni bir barış antlaşması imzalanır. (Sanal olarak.)

---

## 🚀 Nasıl Çalıştırılır?

```bash
python3 muzakereci.py
```

Çalıştırdıktan sonra:
1. Derin bir nefes alın.
2. Ekranı dikkatle izleyin.
3. Uzaylıların cevaplarını saygıyla karşılayın.
4. Dünya barışının bir parçası olduğunuzu hissedin.
